# trellis

Plataforma de colaboração em código alinhada à soberania digital e à interoperabilidade: reutilizar um forge open source existente e desenvolver só o diferencial (identidade portátil, autoria verificável), sem reimplementar Git, issues e pull requests do zero.

**Status:** pré-projeto, em pesquisa. Só o [documento de pesquisa](project/SPEC.md) existe (ainda com o nome de trabalho "Arven Code"); a base tecnológica (Gitea, Radicle ou híbrida) não foi escolhida. Estado em [`project/OVERVIEW.md`](project/OVERVIEW.md).
