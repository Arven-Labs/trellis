# 0001: Nome do projeto: trellis

**Data:** 2026-11-12

## Contexto
O documento de pesquisa usava "Arven Code" como nome de trabalho, dizendo que o nome ainda não estava decidido. O nome acopla o projeto à organização e sugere um GitHub da Arven, que não é o objetivo.

## Decisão
O projeto se chama **trellis** (`Arven-Labs/trellis`).

## Alternativas
- `arven-code`: nome de trabalho; preso à organização e longo para repositório e CLI.

## Consequências
- Treliça: estrutura que sustenta o que cresce sobre ela, coerente com reutilizar uma base existente e acrescentar só o diferencial.
- Risco aceito: há projetos homônimos. Marca e domínio em aberto (`PENDING.md`, P-05).
- O `SPEC.md` mantém "Arven Code" no texto.
